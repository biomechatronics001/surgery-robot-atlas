# Surgery Robot Atlas

**Website: https://biomechatronics001.github.io/surgery-robot-atlas/**

A catalogue of endovascular catheter and guidewire robots: commercial and clinical-stage systems, academic bedside
robots, actuated-tip devices and magnetic navigation, each described with the same fields (devices driven, push and
twist mechanisms, sensing, imaging compatibility, highest validation level and its trials), with pictures, version
histories and sources. It accompanies the review *Endovascular Catheter and Guidewire Robots: A Hardware Atlas*
(in preparation).

- **Library:** filter by family, mechanism, validation level, devices and decade; search by name or group.
- **Robot pages:** the full record, a picture gallery and the cited sources.
- **Data:** `api/robots.json` (one record per robot), `api/stats.json` and a CSV download on the library page; field definitions on the Docs page.

The pages run in a web browser without installation. Pictures are reproduced from the cited papers and company
material and remain under their owners' copyright.

Lab preview, BIRO Lab. The site is generated from the review's catalogue; do not edit these files by hand.
