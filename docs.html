Schema & API

Every robot is one record, validated against a JSON Schema. The compiled catalogue is a set of static JSON files: fetch them directly, no key, no rate limit.

RecordsRobot fieldsControlled vocabularies Example recordFiles and APIFetch examplesschema.org Review and study records

Records

One YAML file per robot in records/robots/<id>.yaml, all with the same fields. Free-text fields keep the wording of the sources, with the source key and section for every number. N.R. means the sources read do not report it; an empty field means nobody has filled it yet.

For now the records are generated from the catalogue CSV that the review's search agents fill (the CSV is the source of truth); the fields marked derived (devices, rotation_mechanism, has_sim_model, read_level) are classified from the free text by tools/build_site.py. Check any record with python3 tools/validate_records.py.

Robot fields

Required fields: schema_version, id, name, full_name, group, family, category, first_year, devices, translation_mechanism, rotation_mechanism, highest_validation, sim2real, picture, sources, read_level, maintainers_own. Examples are from the LegoBot record.

Fetch examples

Replace https://OWNER.github.io/REPO with the address where the site is published; locally, run python3 -m http.server 8000 in the site folder and use http://localhost:8000.

# everything
curl -s https://OWNER.github.io/REPO/api/robots.json -o robots.json
# one robot
curl -s https://OWNER.github.io/REPO/api/robots/legobot_gao2026.json
# robots tested in humans, with jq
curl -s https://OWNER.github.io/REPO/api/robots.json | jq -r '.robots[] | select(.highest_validation=="human") | .name'
import json, urllib.request

BASE = "https://OWNER.github.io/REPO"
data = json.load(urllib.request.urlopen(BASE + "/api/robots.json"))
robots = data["robots"]
human = [r["name"] for r in robots if r["highest_validation"] == "human"]
rollers = [r["id"] for r in robots if r["translation_mechanism"] == "friction-roller"]
print(len(robots), "robots;", len(human), "tested in humans;", len(rollers), "use friction rollers")
const BASE = "https://OWNER.github.io/REPO";
const { robots } = await (await fetch(BASE + "/api/robots.json")).json();
const animal = robots.filter(r => ["animal", "human"].includes(r.highest_validation)).map(r => r.name);
const byPush = robots.reduce((m, r) => (m[r.translation_mechanism] = (m[r.translation_mechanism] || 0) + 1, m), {});
console.log(robots.length, "robots;", animal.length, "tested in animals or humans;", byPush);

schema.org markup

The home page carries a Dataset (name, description, creator, variables, JSON and CSV DataDownloads) for dataset search engines; the library page an ItemList of robot pages; each robot page a Thing whose subjectOf lists its papers as ScholarlyArticles with DOIs; the reviews page an ItemList of ScholarlyArticles. Absolute URLs are filled when the site is built with --base-url.
